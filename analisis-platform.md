# Analisis Komparatif Platform

Berikut adalah tabel perbandingan karakteristik antara platform Web, Desktop, dan Mobile:

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| **Bahasa utama** | HTML, CSS, JavaScript | C++, C#, Java | Kotlin, Swift, Dart |
| **Arsitektur** | Client-Server | Standalone | Client-Server / Native |
| **Cara distribusi** | Browser / URL | Installer / App Store | Play Store / App Store |
| **Keunggulan** | Lintas platform, tanpa instalasi, mudah diakses | Performa komputasi tinggi, akses penuh ke sistem OS | Portabel, akses sensor bawaan (GPS, kamera) |
| **Keterbatasan** | Sangat bergantung pada koneksi internet | Terbatas pada Sistem Operasi tertentu (Windows/Mac/Linux) | Ukuran layar terbatas, kapasitas baterai terbatas |
| **Contoh aplikasi** | Google Docs, YouTube, Figma | Microsoft Office, Adobe Premiere, Blender | WhatsApp, Gojek, Instagram |
